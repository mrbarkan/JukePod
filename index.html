      Know of a firmware missing here?

      Send the details and it goes on the page. A listing needs:

      • Name, maker and a sentence on what it does
      • The iPods it runs on, and any it only partly supports
      • A public download link and the source repository
      • Install steps, the license, and checksums if you publish them

      Every listing lives in one file

      data/firmwares.js

      Open a pull request that adds your entry, or open an issue with the details and it will be added for you.

      Open an issue Edit the file on GitHub ↗

      Back up your music before you install anything. Every firmware here is made by independent developers and installed at your own risk.
